# Product Overview

## Что это
Smart Quote & CAM-Costing System — двухконтурное промышленное веб-приложение для быстрой оценки стоимости CNC-механообработки (коммерческие предложения) и точных технологических расчётов 2.5D-документации для цеха.

Первичный источник истины: `Описание и план приложения.docx` в корне проекта (подробный Master Blueprint на ~1000 строк).

## Зачем существует
- Проблема: расчёт трудоёмкости по чертежам требует связки «техпроцесс → нормы времени → ставка часа → себестоимость»; существующие инструменты (Excel, 1С, CAD-эстиматоры) либо медленные, либо неточные, либо требуют 3D-модели, которых у клиентов нет (2D PDF-чертежи — 60-70% входящего потока).
- Цель: КП за 15 минут (вместо дней) + точная цеховая калькуляция после подписания договора.

## Два контура (ключевая концепция)
1. **Контур А — Коммерческий (ТКП/КП)**: скорость важнее точности. Параметрический 2.5D-конструктор + метод аналогов + коэффициент риска (+15-20%). Результат — цена за 15 минут.
2. **Контур Б — Технологический**: точность важнее скорости. Пооперационный маршрут технолога, точное Tшт (вплоть до парсинга G-кода/отчётов CAM). Результат — цеховая себестоимость и сдельная оплата.

Оба контура работают на единой БД справочников (единый источник истины по ставкам, материалам, режимам).

## Как работает (конвейер расчёта)
1. Заявка + парсинг КД (3D OpenCascade: Vnet, Asurf, Bounding Box; 2D OCR/CV: штамп, материал, квалитеты, Ra, ТТ).
2. Подбор заготовки + материальные затраты (Vgross → Mgross, Vrem = Vgross − Vnet, учёт стружки, MOQ, некратности раскроя).
3. Генерация маршрута (Контур 1 — Rule Engine автоматически; Контур 2 — технолог в редакторе, установы, оснастка).
4. Нормирование времени: To (объёмно-поверхностный метод: Vrem/Q + Asurf/S, либо попереходный/CAM), Tв (таблицы нормативов), Tшт-к = (To+Tв)·(1+α) + Tпз/N.
5. Финансовая калькуляция: многокомпонентная ставка минуты станка (амортизация, энергия, ФОТ, инструмент, ОПР/ОХР).
6. Динамическое ценообразование (APS): маржа зависит от загрузки группы станков Ugroup (простой <40% → скидка; перегруз >95% → Surge Pricing ×1.8-2.5), Floor Costing — защита от демпинга.

## 2.5D-конструктор (Feature-Based Costing Builder)
- Решает проблему отсутствия 3D: менеджер выбирает шаблон (T1 вал, T2 втулка, T3 фланец, T4 плита, T5 корпус, T6 лист+гибка), вводит габариты с клавиатуры (Tab/Numpad), добавляет модификаторы (отверстия, пазы, резьбы, канавки) без точных координат — важны только количество, диаметр, глубина, тип.
- Математика — CSG (булева алгебра примитивов): из базового объёма вычитаются отрицательные объёмы фич → Vnet, Vrem, Asurf.
- 3D-болванка рендерится в браузере (Three.js) для визуальной сверки с чертежом (защита от опечаток).
- Каждая фича автоматически прописывает операции в маршрут.
- Планируется (OpenSCAD, план 2026-11-03, не реализовано): три режима ввода геометрии — шаблоны T1..T5 (как сейчас), параметрический Customizer по переменным .scad-кода, вставка готового OpenSCAD-кода; точные объёмы/площади из скомпилированной сетки при неизменном расчётном ядре (маршрут, сверление, корзины — без изменений).

## Расширения за пределы одной детали
- Древовидный расчёт сборок (BOM, ПКИ, консолидация партий одинаковых деталей).
- Сценарий деградации данных (сканы синек, фото из WhatsApp) → покрыт 2.5D-конструктором.
- Контур закупщика: MOQ, заморозка цен поставщиков.
- Листообработка (лазер/плазма, гибка, nesting) и сварка (катет шва, объём наплавки, Arc-on Time, Karc 0.3-0.45).
- Цикл обратной связи План/Факт через MES (сравнение расчётного и фактического времени, автокоррекция нормативов).

## UX-цели
- Single-Screen Workspace: левая панель 30% (3D + 2D с маркерами ИИ), центр 45% (конструктор маршрута: «Быстро» — карточки, «Точно» — аккордеон операций), правая панель 25% (Live Cost Breakdown: круговая диаграмма структуры цены, светофор риска, цены по тиражам).
- Ввод без мыши (Tab + Numpad), живой пересчёт при любом изменении параметра.
- Роли: Менеджер (минимум полей), Технолог (глубокий конструктор ТП), Админ, Закупщик.
